# ダンジョン 151〜300階

150階の応用情報エリアを越えた先を、分野別の実践と総合復習へつなぐ追加コンテンツ。
既存の1〜150階の配置・報酬を保ち、151階からそのまま進める。

問題は既存の10種類の分野別問題集を再利用する。新規問題の追加は含まない。
複合エリアは分野ごとにシャッフルして交互に出題し、設問文が同じ問題は重複させない。

## 進行と報酬

小エリア内の1・6階目は通常マス、2・3・5・7・9階目は通常戦、
4階目はコイン宝箱、8階目は補給宝箱。10階目は通常マスで、
200・250・300階だけは独立した大きな足場のボス戦になる。
通常マスでは既存のライバル遭遇が発生する場合もある。
追加分は通常戦75・ボス戦3・宝箱30・通常マス42の計150階。

- コイン宝箱：1,500〜2,900コイン。小エリアごとに100コインずつ増える。
- 補給宝箱：スタミナ回復薬1個と、3回分の戦闘ブースト。
- 198階：補給アイテムをレアガチャチケット1枚に置換。
- 248階：補給アイテムをメカガチャチケット1枚に置換。
- 298階：補給アイテムをブーストチケット1枚に置換。
- 200階：メカガチャチケット1枚、スタミナ回復薬2個。
- 250階：神ガチャチケット1枚、ブーストチケット1枚。
- 300階：神ガチャチケット2枚、ブーストチケット2枚。

通常敵はHP1,000〜2,400、攻撃360〜570。
大ボスは200階がHP6,000/攻撃550、250階がHP7,500/攻撃625、
300階がHP9,000/攻撃700。難易度は育成済みプレイヤーを想定した初期設定で、
実プレイによる調整は別途必要。

## 実装

内容定義は `Quiz/DungeonExpansion.swift` に集約する。
通常敵IDは「1,000＋登場階」で、通常戦75マスごとに一意のIDを持つ。
ボスIDは105・110・115、宝箱IDは31〜60。敵のID・表示名と画像名を分離する。
各章の足場は既存の青い結晶・ルーン・結晶の画像に切り替える。
敵パラメータは戦闘前表示と実戦で同じ定義を参照する。

2026年10月6日、ブラウザ版ChatGPTで通常敵75種類を生成した。
1エリアの通常戦5マスに、異なる種族・体形・シルエットのモンスターを1体ずつ割り当てる。
例えば152・153・155・157・159階は、それぞれコウモリ・甲虫・エイ・キツネザル・ムカデ。
画像アセットは `DungeonFloorMonster152` のように登場階を含む。
通常敵75種類と大ボス3種類を合わせて78体。通常敵のHP・攻撃・報酬はエリアの既存設定を保つ。
75個の512×512透過PNG、9枚の生成シート、送信プロンプト、ChatGPTの会話URL、
階別の名称・アセット一覧、生成画面、一覧画像は
`output/imagegen/dungeon-unique-monsters-151-300-2026-10-06/` に保存した。

宝箱30種類は `DungeonExpansionTreasure31`〜`DungeonExpansionTreasure60` を参照する。
各10階エリアにコイン宝箱1種類・補給宝箱1種類を割り当てる。
宝箱の生成元は `output/imagegen/dungeon-expansion-151-300-2026-10-06/` に保存した。

## 確認コマンド

```sh
python3 Tests/DungeonExpansionTests.py
python3 Tests/DungeonDeveloperModeTests.py
python3 Tests/DungeonBattleRegressionTests.py
python3 Scripts/test-dungeon-lifecycle.py
```

拡張テストは実際のカタログ・旧マップ・問題配列をSwiftでコンパイルして実行し、
1〜300階の一意性、各エリアの問題、報酬、画像参照を検証する。
移動テストはDebug/Releaseの双方で章境界と最終階を確認する。
